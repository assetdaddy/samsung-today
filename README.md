# 칠문(七門) — 페이블의 운명 점방 🏮

동서고금의 일곱 점술을 **하나의 우화(寓話)로 직조**하는, 세상에 없던 통합 운명 리딩 웹앱.

일곱 개의 문을 차례로 지나면, 흩어져 있던 점괘들이 마지막 직조실에서
**① 오행 융합 리포트 ② 나만의 운명 문장(紋章, 제너러티브 아트) ③ 내 운명을 담은 한 편의 우화**로 짜여 나옵니다.

## 일곱 개의 문

| 문 | 점술 | 방식 |
|---|---|---|
| 一門 문패 | 기본 정보 | 이름 · 생년월일시 입력 (시간 모름 지원) |
| 二門 여덟 글자 | 사주명리 | 만세력 자체 계산 — 연·월·일·시주, 오행 분포, 일간 해석, 십신 구조 |
| 三門 별 | 서양 점성 | 태양궁 12궁 + 태어난 밤의 달 위상(8단계) |
| 四門 얼굴 | 관상 | 오관(五官) 특징을 직접 골라 풀이 |
| 五門 손 | 손금 | **화면에 직접 손금 3선을 그리면** 길이·곡률을 분석해 풀이 |
| 六門 시간 | 주역 | 동전 세 닢 육효점 — 본괘·변효·지괘, 64괘 전체 해석 수록 |
| 七門 그림 | 타로 | 메이저 아르카나 22장 중 3장 (과거·현재·미래, 역방향 포함) |

## 세상에 없는 부분 — 직조실

일곱 문의 결과를 오행(木火土金水) 점수로 환산·융합하여:

- **주(主) 기운 / 보(補) 기운** 진단과 행운의 색·방위·숫자·계절·덕목
- **운명 문장(紋章)**: 12궁 링 + 오행 오각형 + 육효 + 타로 별 + 달 위상을 한 장의 인장으로 그리는 캔버스 제너러티브 아트 (PNG 저장 가능)
- **운명 우화**: 띠 동물이 주인공이 되어, 별자리의 무대에서 주역의 수수께끼를 만나고 타로의 정령에게 조언을 듣는 — 매번 다르게 생성되는 한 편의 짧은 우화

## 실행

빌드·서버 불필요. 정적 파일이므로 그냥 열면 됩니다.

```bash
open index.html        # 또는
python3 -m http.server # http://localhost:8000
```

## 구조

```
index.html      화면 마크업 (7문 + 직조실)
css/style.css   밤하늘 점방 테마
js/data.js      천간지지 · 십신 · 12궁 · 달 위상 · 관상 · 손금 · 64괘 · 타로 22장 · 우화 재료
js/engine.js    만세력(절기 근사) · 달 위상 · 육효 캐스팅 · 손금 획 분석 · 오행 융합 · 우화 생성 · 문장 렌더러
js/app.js       화면 흐름 · 별밭 배경 · 캔버스 인터랙션
```

만세력 일주 계산은 1900-01-01(甲戌日) 기준 60갑자 순환식이며, 1949-10-01(甲子日) 등 앵커로 검증했습니다.
월주는 절기(입춘·경칩…) 평균 절입일 근사를 사용합니다.

> ※ 본 점방의 풀이는 전통 상수(象數)의 상징을 빌린 창작 이야기이며, 재미와 성찰을 위한 것입니다.
