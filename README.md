# 칠문(七門) — 페이블의 운명 점방 🏮

여섯 점술을 **각각 독립된 문**으로 보는 운명 점방 웹앱.
대문에서 끌리는 문 하나만 열어도 되고, 여섯 문을 모두 연 이에게는 보너스 — 점괘를 **하나의 문장(紋章)과 우화(寓話)로 직조**하는 직조실이 열립니다.

## 여섯 개의 문 (각각 독립)

| 문 | 점술 | 방식 |
|---|---|---|
| 사주명리 | 四柱命理 | 만세력 자체 계산 — 아래 상세 |
| 점성 | 占星 | 태양궁 12궁 + 태어난 밤의 달 위상(8단계) |
| 관상 | 觀相 | 오관(五官) 특징을 직접 골라 풀이 |
| 손금 | 手相 | **화면에 직접 손금 3선을 그리면** 길이·곡률을 분석해 풀이 |
| 주역 | 周易 | 동전 세 닢 육효점 — 본괘·변효·지괘, 64괘 전체 해석 수록 |
| 타로 | TAROT | 메이저 아르카나 22장 중 3장 (과거·현재·미래, 역방향 포함) |

이름·생년월일시·성별은 사주·점성 두 문에서만 필요하며, 한 번 적으면 공유됩니다(문패).

## 사주명리 상세 분석

- **원국 표**: 연·월·일·시주 + 글자별 십신(十神) 10종 개별 표기 + 지장간(支藏干) + 십이운성(十二運星)
- **일간·격국**: 일간 본질 풀이, 월지 본기 기준 간이 격국(건록격·양인격·○○격)
- **일주 깊이 읽기**: 배우자궁(일지)의 십신과 십이운성 조합 해석
- **신강·신약 판정**: 인성·비겁 가중 점수(월지 3 · 일지 2 · 시지 1.5 · 연지 1 · 천간 1) → 신강/중화/신약 + 간이 억부 용신(用神)
- **신살(神殺)**: 천을귀인 · 역마 · 도화 · 화개 · 양인 · 괴강 · 백호
- **대운(大運)**: 양남음녀 순행/역행, 절입일 거리 ÷3 대운수, 8개 대운 타임라인(현재 대운 하이라이트)
- **세운(歲運)**: 올해 간지의 십신으로 읽는 한 해 흐름

## 보너스 — 직조실

여섯 문의 결과를 오행(木火土金水) 점수로 환산·융합하여:

- **주(主) 기운 / 보(補) 기운** 진단과 행운의 색·방위·숫자·계절·덕목
- **운명 문장(紋章)**: 12궁 링 + 오행 오각형 + 육효 + 타로 별 + 달 위상을 한 장의 인장으로 그리는 캔버스 제너러티브 아트 (PNG 저장 가능)
- **운명 우화**: 띠 동물이 주인공이 되어, 별자리의 무대에서 주역의 수수께끼를 만나고 타로의 정령에게 조언을 듣는 — 매번 다르게 생성되는 한 편의 짧은 우화




## 신살·십이운성 심층 + 운영자 공부 탭

- **십이운성(十二運星) 심층**: 일간이 각 기둥 지지에서 거치는 장생·목욕·관대·건록·제왕·쇠·병·사·묘·절·태·양 12단계를 「단계 비유 · 성향 · 자리별 뜻 · 주의」로 상세 분석하고, 기세(왕성/약함)를 뱃지로 표시.
- **신살(神殺) 심층**: 천을귀인·역마·도화·화개·양인·괴강·백호에 **원진·홍염·문창귀인·공망**을 더해 11종. 각 살을 「의미·유래 · 좋게 쓰면 · 과하면 · 해석 tip」으로 풀어, *어떻게 해석·활용하면 좋은지*까지 안내.
- **운영자 공부 탭(admin.html › 📚 용어 공부)**: 십신·십이운성·신살·오행·파자를 검색 가능한 사전 카드로 모아, 담당자가 용어와 해석법을 학습할 수 있는 자료로 제공.

## 궁합 · 결과 공유 · 실제 DB 연동

- **궁합(宮合) 문**: 두 사람의 사주로 인연을 분석 — 일간 십신(서로를 어떻게 느끼는가, 양방향), 띠·배우자궁의 **합충(삼합·육합·충)**, 두 사주 오행을 합친 **상보 균형**, 종합 점수·등급.
- **결과 저장·공유**: 리딩 상태를 URL 해시로 직렬화(`#s=…`)해 **링크 한 줄로 공유**. 링크를 열면 그대로 복원됩니다(궁합·직조실 결과 등). 운명 문장(紋章)은 PNG로 저장.
- **실제 DB 연동**: 콘텐츠 오버라이드를 REST 서버와 동기화. 저장소의 `server/server.js`(의존성 0, Node 내장 모듈)를 실행하고 운영자 콘솔 "🔌 DB 연동"에 엔드포인트를 넣으면 서버로 저장/불러오기·자동 로드가 됩니다.

## 사주 상세 분석 (심화)

- **근묘화실(根苗花實)**: 네 기둥의 궁위 — 연주=조상·초년(뿌리), 월주=부모·사회·청년(싹), 일주=나·배우자·중년(꽃), 시주=자녀·말년(열매) — 를 각 자리의 십신·십이운성과 엮어 해석.
- **십신 심층 분석**: 팔자에 실제로 뜬 십신을 **키워드 다발·심리·강점·그림자(과다)·직업·관계** 6개 층으로 해부(예: 정인 = 학문·문서에 더해 기록·과거 회상·미련·향수까지).
- **오행 분석**: 과다·고립(없는) 오행에 대한 개별 코멘트와 보완 방향.

## 파자(破字) 풀이 · 테마 상세 해설

- **파자 풀이**: 한자를 뜻이 아니라 *생김새*로 다시 읽습니다. 예) 卯(묘)는 양쪽으로 열린 문이라 가운데가 뻥 뚫려 — 속을 열어 보이고 말하기 좋아하는 소통의 글자. 천간 10자·지지 12자를 페이블식 상상 해석으로 담았고, 사주 원국의 여덟 글자를 골라 풀어 줍니다.
- **테마 상세 해설**: 여섯 문마다 "이 문은 무엇을 보는가"를 새롭고 쉬운 비유로 설명하는 접이식 해설(사주=타고난 계절, 점성=태어난 순간의 하늘 사진, 관상=얼굴에 쓰인 시간표, 손금=손에 새겨진 강줄기, 주역=지금 던지는 질문, 타로=그림으로 온 편지).

## 운영자 콘솔 (`admin.html`)

담당자용 페이지. 두 개 탭:

1. **설명서(판정 규칙)** — 오행 상생·상극, 천간/지지/지장간, **십신 10×10 매트릭스**, **십이운성 10×12 표**, 신강약 판정식, 용신·격국, 신살 성립조건과 대조표(천을귀인·삼합), 대운/세운, 별자리 경계, 달·관상·손금·주역·타로·직조 규칙. **모두 실제 상수·엔진에서 생성**되어 코드와 항상 일치.
2. **콘텐츠 DB 관리** — 사람이 읽는 풀이 텍스트를 16개 테이블로 편집. 검색 필터, localStorage 저장, **JSON 내보내기/불러오기**, 전체 초기화. 저장한 오버라이드는 앱 로드 시 자동 병합됩니다.

## 관상·손금 사진

- **관상**: 카메라 촬영 또는 사진 업로드 → 사진을 보며 오관 선택 (결과에 사진 첨부)
- **손금**: 손바닥을 촬영/업로드 → **그 사진 위에** 세 손금을 덧그려 길이·곡률 분석
- 카메라 미지원 기기에서는 파일 업로드로 폴백됩니다.

## 실행

빌드·서버 불필요. 정적 파일이므로 그냥 열면 됩니다.

```bash
open index.html        # 또는
python3 -m http.server # http://localhost:8000
```

## 구조

```
index.html      화면 마크업 (허브 + 6개 독립 점술 + 직조실)
css/style.css   밤하늘 점방 테마
js/data.js      천간지지 · 십신 10종 · 지장간 · 십이운성 · 신살 · 12궁 · 달 위상 · 관상 · 손금 · 64괘 · 타로 22장 · 파자(천간·지지) · 테마 해설 · 우화 재료
js/engine.js    만세력(절기 근사) · 사주 심화(십신·운성·신강약·용신·신살·대운·세운) · 달 위상 · 육효 · 손금 분석 · 융합 · 우화 · 문장 렌더러
js/content-db.js 풀이 텍스트 오버라이드 레이어(16개 테이블) · localStorage 병합
js/app.js       허브 흐름 · 카메라(관상·손금) · 별밭 배경 · 캔버스 인터랙션
admin.html      운영자 콘솔 — 판정 규칙 설명서 + 콘텐츠 DB 관리
```

만세력 일주 계산은 1900-01-01(甲戌日) 기준 60갑자 순환식이며, 1949-10-01(甲子日) 등 앵커로 검증했습니다.
월주는 절기(입춘·경칩…) 평균 절입일 근사를 사용합니다.

> ※ 본 점방의 풀이는 전통 상수(象數)의 상징을 빌린 창작 이야기이며, 재미와 성찰을 위한 것입니다.
